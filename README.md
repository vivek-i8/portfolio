# Vivek Kumawat

Portfolio application for Vivek Kumawat, an AI and Software Engineer based in Bengaluru, India.

## Tech Stack

- **Framework:** Next.js 16 (App Router), React 19, TypeScript
- **Styling:** Tailwind CSS, Radix UI
- **Animation & Graphics:** GSAP, Framer Motion, Lenis, Spline 3D
- **Backend & State:** Next.js Route Handlers, PostgreSQL, Redis, Docker
